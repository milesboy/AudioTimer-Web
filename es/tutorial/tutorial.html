Tutorial de Audio Timer

Tu temporizador con voz para entrenamientos e intervalos

1. Crea tu entrenamiento

  • Toca el icono del engranaje → Pantalla de configuración
  • Elige el Número de temporizadores (1–10)
  • Puedes deslizar el selector de número de temporizadores arriba o abajo si el número deseado no está visible
  • Configura para cada temporizador la Duración, las Repeticiones y, si quieres, una Pausa entre repeticiones

2. Ajustes globales

  • Pausa inicial – cuenta atrás antes de que empiece el primer temporizador
  • Pausa entre secuencias – descanso al terminar un ciclo completo
  • Intervalo de avisos – la voz anuncia el tiempo restante cada X segundos

3. Guarda tu preset

  • Toca “Guardar como preset”
  • Dale un nombre (ej: “Tabata”, “EMOM 60”, “HIIT 30/10”)
  • Aparecerá inmediatamente en la lista de presets

4. Ejecuta tu temporizador

  • Vuelve atrás → toca el gran botón Start
  • Una voz clara te guiará durante todo el entrenamiento
  • Tienes botones Repetir y Siguiente por si necesitas saltarte algo
  • También tienes botón Pausa. Mientras está en pausa, puedes tocar el tiempo grande para establecer un nuevo tiempo de cuenta atrás
Truco profesional: ¡La pantalla permanece encendida y el audio funciona perfectamente aunque bloquees el móvil!

5. Gestiona tus presets

Toca cualquier preset en la lista de la pantalla principal para cargarlo al instante.

Eliminar un preset:
Desliza cualquier preset hacia la izquierda → se borrará.

¿Te has equivocado? Aparece un mensaje con botón “DESHACER” durante unos segundos — tócalo para recuperarlo inmediatamente.
